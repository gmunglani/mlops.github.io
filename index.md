# Data Protection and Privacy

This page serves as the main entry point for our data protection policies and commitment to user privacy.

## Our Commitment

We take your privacy seriously. This document outlines how we collect, use, and protect your personal information on this site.

### 1. Data Collection

We do **not** use cookies, analytics, or third-party tracking services. Since this site is built using Jekyll and hosted via GitHub Pages, it primarily generates static HTML.

* **Information Collected:** None directly. Your browser's IP address and access logs may be retained by the GitHub Pages server for security and operational reasons.
* **Third Parties:** We do not share any data with third-party organizations.
